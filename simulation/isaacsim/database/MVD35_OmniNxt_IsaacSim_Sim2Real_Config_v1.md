# MVD35 + OmniNxt式载荷：Isaac Sim / Pegasus 仿真配置修改说明（V1）

## 1. 文档目的

本文件用于指导 Codex 在现有 Isaac Sim / Pegasus 四旋翼项目中，将无人机物理模型调整为以下目标平台的第一版工程估计：

- MicoAir MVD35 3.5英寸圈圈机架；
- 2004 2100KV 电机 ×4；
- 3.5英寸三叶桨 ×4；
- 6S 1500mAh 电池；
- Jetson Orin NX 16GB、紧凑载板、SSD、网卡和散热器；
- OAK-FFC-4P；
- OV9782 鱼眼相机 ×4；
- 按 OmniNxt Corner 结构环绕安装四相机；
- 目标用途：Omni-Depth、室内无人机飞行、后续 Sim2Real。

本文件中的质量、重心、惯量和电机参数是装机前的第一版估计，不是实测标定值。代码修改时必须保留参数集中配置能力，便于实机完成后替换。

---

## 2. Codex执行要求

修改代码前先完成以下检查：

1. 搜索现有无人机配置、USD、Python/YAML/JSON参数文件和动力插件实现。
2. 确认当前项目使用的是 Pegasus Simulator、PX4 SITL、自定义动力模型还是其他接口。
3. 确认坐标系：机体系是 FLU、FRD、ENU 还是 NED。
4. 确认电机编号、位置顺序及 CW/CCW 定义。
5. 确认旋翼速度单位是 rad/s、RPM 还是归一化控制量。
6. 确认推力模型究竟是 `F = k_f * omega^2`，还是插件内部采用其他定义。
7. 确认 `moment_constant` 是 `k_m`、`k_m/k_f`，还是插件特定无量纲量。
8. 确认质量和惯量由根刚体统一设置，还是由多个子刚体自动合成，避免重复计重。
9. 不要仅因字段名称相似就直接替换数值；必须根据源码中的公式和单位映射。
10. 修改后输出变更文件、字段映射、单位以及无法确定的参数。

第一轮只修改物理参数和必要的传感器频率，不主动重调控制器增益。先验证新物理模型，再决定是否调整控制器。

## 4. 刚体参数

### 4.1 总质量

第一版设置：

```yaml
mass: 0.83  # kg
```

质量估计包含MVD35动力平台、6S电池、飞控/电调、Orin NX计算总成、OAK板、四个相机、支架和线材。

后续实机装配完成后，必须用完整起飞状态称重替换：

```text
含电池、桨叶、Jetson、OAK板、4个相机、支架、所有线材和固定件。
```

### 4.2 重心

假设机体系采用 `x前、y左、z上`，第一版设置：

```yaml
center_of_mass: [0.0, 0.0, 0.008]  # m
```

建议范围：

```yaml
com_x: [-0.005, 0.005]
com_y: [-0.005, 0.005]
com_z: [0.003, 0.018]
```

如果项目采用FRD（z向下），必须将z符号转换。不要直接复制上述正负号。

### 4.3 惯量矩阵

以整机重心为参考点：

```yaml
inertia:
  ixx: 0.00150
  iyy: 0.00165
  izz: 0.00260
  ixy: 0.0
  ixz: 0.0
  iyz: 0.0
```

完整矩阵：

```text
I = [[0.00150, 0,       0      ],
     [0,       0.00165, 0      ],
     [0,       0,       0.00260]] kg·m²
```

如果USD通过多个刚体自动计算惯量，不要同时在根刚体重复写入同一质量和惯量。优先将无人机简化为单一主刚体，旋翼只作为施力点或视觉部件。

## 5. 旋翼几何

MVD35对角电机轴距：

```text
L = 0.152 m
```

对称X型布局的坐标绝对值：

```text
a = L / (2*sqrt(2)) = 0.05374 m
```

相对于重心，电机平面暂定低8 mm：

```yaml
rotor_positions:
  - [ 0.05374,  0.05374, -0.008]
  - [ 0.05374, -0.05374, -0.008]
  - [-0.05374, -0.05374, -0.008]
  - [-0.05374,  0.05374, -0.008]
```

重要：上述顺序不是强制电机编号。Codex必须根据当前项目电机编号和坐标系重新排列。

桨叶参数：

```yaml
propeller_diameter: 0.0889  # m
propeller_radius: 0.04445   # m
```

旋翼轴应与机体竖直轴平行。根据FLU/FRD约定设置推力方向。

## 6. 电机与螺旋桨模型

### 6.1 悬停检查

0.83 kg整机的悬停总推力：

```text
T_hover = m*g = 0.83*9.81 = 8.1423 N
```

单电机悬停推力：

```text
T_hover_motor = 8.1423/4 = 2.0356 N ≈ 207.5 gf
```

### 6.2 最大推力

第一版保守设置：

```yaml
max_thrust_per_rotor: 6.5  # N
```

对应整机推重比：

```text
TWR = (4*6.5)/(0.83*9.81) ≈ 3.19
```

### 6.3 最大转速和推力系数

假设插件公式为：

```text
F = k_f * omega²
```

且 `omega` 单位为 rad/s，则：

```yaml
max_rotor_velocity: 3800.0
thrust_coefficient: 4.50e-7
```

计算关系：

```text
k_f = 6.5 / 3800² ≈ 4.50e-7 N/(rad/s)²
```

如果插件中的转速单位是RPM，则必须重新换算，禁止直接使用4.50e-7。

### 6.4 偏航反扭矩

假设：

```text
M = k_m * omega²
```

第一版使用：

```yaml
moment_coefficient: 5.40e-9  # N·m/(rad/s)²
```

等价比值：

```text
k_m/k_f ≈ 0.012 m
```

如果代码字段 `moment_constant` 表示的是 `k_m/k_f`，应填写0.012，而不是5.40e-9。

### 6.5 电机响应

若使用一阶模型：

```text
d(omega)/dt = (omega_command - omega)/tau
```

设置：

```yaml
time_constant_up: 0.035
time_constant_down: 0.055
```

如果当前动力模型没有执行器动态，应增加一阶低通响应或明确记录仍使用理想电机模型。

### 6.6 电机旋向

必须保持相邻电机旋向相反、对角电机旋向相同，例如：

```text
CCW / CW / CCW / CW
```

具体顺序必须匹配当前PX4机架和控制分配矩阵。

## 8. 空气阻力

MVD35带3.5英寸保护圈、中央计算堆叠和四角相机，阻力高于开放式竞速四旋翼。

若项目使用：

```text
F_drag = -0.5*rho*CdA*|v|*v
```

第一版使用：

```yaml
drag_area_coefficient:
  x: 0.030  # m²
  y: 0.032  # m²
  z: 0.055  # m²
```

建议范围：

```yaml
cdA_x: [0.020, 0.045]
cdA_y: [0.020, 0.048]
cdA_z: [0.040, 0.075]
```

如果当前插件采用线性阻尼、旋翼阻力系数或其他模型，不要把上述CdA数值直接写入。第一版可以保留原阻力模型，并在修改报告中说明。

## 10. 仿真与控制频率

```yaml
physics_frequency: 500
motor_update_frequency: 500
attitude_control_frequency: 250
position_control_frequency: 50
camera_frequency: 20
omni_depth_frequency: 15
```

如果当前仿真无法稳定达到500 Hz，可退到250 Hz，但不建议使用60 Hz物理步长模拟该小型四旋翼。

对应步长：

```text
500 Hz -> dt = 0.002 s
250 Hz -> dt = 0.004 s
```

除非现有配置无法悬停，否则第一轮不要主动修改：

- 位置控制器增益；
- 速度控制器增益；
- 姿态控制器增益；
- 角速度控制器增益；
- PX4内部估计器参数；
- 用户现有安全限制；
- 与本任务无关的场景和传感器代码。

用户此前可用的控制器初值为：

```python
kp_pos = (0.6, 0.6, 6.0)
kd_vel = (3.0, 3.0, 4.5)

```

只有在物理参数修改后出现持续振荡、严重超调或无法跟踪时，再基于阶跃测试重新调整。

## 13. 修改后的验证要求

### 13.1 静态检查

- 仿真单位为m、kg、s、rad/s；
- 总质量只计算一次；
- 惯量矩阵正定；
- 4个旋翼位置与152 mm对角轴距一致；
- 旋翼推力方向正确；
- CW/CCW与控制分配一致；
- 重力为9.81 m/s²左右。

### 13.2 悬停检查

- 悬停总推力约8.14 N；
- 单电机悬停推力约2.04 N；
- 四电机稳态输出应基本对称；
- 悬停时不应接近最大电机输出；
- 无指令情况下不应持续产生明显横滚、俯仰或偏航。

### 13.3 动态检查

依次运行：

1. 起飞到1.5 m并悬停10 s；
2. x方向1 m位置阶跃；
3. y方向1 m位置阶跃；
4. z方向0.5 m高度阶跃；
5. 偏航90°阶跃；
6. 1 m/s速度指令；
7. 紧急减速至0 m/s。

记录：

- 上升时间；
- 超调量；
- 稳态误差；
- 最大倾角；
- 最大电机输出；
- 位置和姿态振荡；
- 控制饱和情况。

### 13.4 代码验证

- 运行现有测试；
- 至少完成一次无GUI或短时仿真启动；
- 检查日志无NaN、惯量错误、刚体警告和电机饱和异常；
- 不因修改参数破坏现有场景加载和无人机生成流程。

## 15. 装机完成后的替换顺序

实物完成后，按以下优先级更新：

1. 实测完整起飞质量；
2. 实测三轴重心；
3. 悬停油门和飞行日志；
4. 实测或CAD计算惯量；
5. 电机—桨叶推力台架曲线；
6. 电机转速阶跃时间常数；
7. 电池压降和内阻；
8. 飞行减速数据辨识空气阻力；
9. 相机真实内外参；
10. 图像、Omni-Depth和控制链路实测延迟。

对Sim2Real影响优先级：

```text
质量与重心 > 推力模型 > 惯量 > 电机延迟 > 感知延迟 > 电池压降 > 空气阻力
```
