# OmniDepth 真机视差替代与点云质量改进方案

日期：2026-07-30

## 结论

当前四扇区朝向错误已经修复，四组点云分别指向右、后、左、前。剩余的主要问题位于视差估计，而不是四相机外参或点云坐标变换。

真机最可行的实施路线：

1. 保留现有标定、虚拟双目矫正、Q 重投影和扇区外参。
2. 将视差后端改成可切换的 `hitnet / sgbm3way / vpi_sgm / hybrid`。
3. 先用 OpenCV `StereoSGBM MODE_SGBM_3WAY` 建立可靠、可解释的真机基线。
4. 再接入 JetPack 5.1.2 自带 VPI 2.2 的 CUDA SGM，争取更好的速度和置信度输出。
5. 最终优先使用 SGM 高置信度点；只有 HITNet 与 SGM、左右一致性及光度检查同时相符时，才允许 HITNet 补充稠密点。

不建议直接把 RAFT-Stereo 或 CREStereo 作为第一步。它们在当前 Orin Nano 8GB、JetPack 5.1.2、四组 320×240 双目、目标 5–10 Hz 条件下，模型转换、显存、TensorRT 算子和域适配风险都高于传统 SGM。

## 当前证据

### 几何链路

已经修复：

- Kalibr `T_cam_imu` 方向使用错误；
- 虚拟左相机矫正旋转 `R1` 未被正确逆变换的问题。

修复后扇区方向：

- A-B：右侧；
- B-C：后侧；
- C-D：左侧；
- D-A：前侧。

因此当前“像薄片、错误表面、噪声密集”的问题不能再主要归因于扇区朝向或外参方向。

### HITNet 表现

当前 HITNet 对每组 320×240 图像几乎给所有 19,200 个像素输出正视差，四组共 76,800 点。它没有可靠地区分：

- 遮挡区域；
- 左右图无共同视野区域；
- 低纹理地面和墙面；
- 反光与过曝区域；
- 虚拟双目矫正后的黑边；
- 相机间曝光和颜色差异。

关闭过滤后点数增加到 76,800，但错误表面同步增加，说明“点少”不是根因，原始视差的有效性才是根因。

### SGBM 真机性能预估

在当前保存的四组 320×240 矫正图上实测：

| 后端 | 四组总耗时均值 | 理论频率 | 各扇区有效视差比例 |
|---|---:|---:|---|
| 标准 SGBM | 133.2 ms | 7.5 Hz | 21.4%、32.2%、22.5%、14.4% |
| SGBM 3WAY | 32.8 ms | 30.5 Hz | 21.6%、30.0%、23.1%、15.1% |

这些数据只包含核心匹配，不包含 ROS、矫正、重投影和发布开销，但足以说明 SGBM 3WAY 在当前 Orin Nano 上有实现 5–10 Hz 在线处理的余量。

稀疏但可信的点云比稠密错误点云更适合避障和后续融合。

## 第一阶段：实现 SGBM 3WAY 基线

### 配置建议

新增配置：

```yaml
disparity_backend: sgbm3way

sgbm:
  min_disparity: 0
  num_disparities: 96
  block_size: 5
  p1: 200
  p2: 800
  disp12_max_diff: 1
  pre_filter_cap: 31
  uniqueness_ratio: 12
  speckle_window_size: 80
  speckle_range: 2
  mode: sgbm_3way
```

这组参数是起点，不是最终值。应使用固定的真机场景和实测距离调参。

### 代码改造

当前 `VirtualStereo::estimateDisparityOCV()` 已经存在，但在线推理线程被硬编码为 HITNet。需要：

1. 在在线线程读取 `disparity_backend`；
2. `hitnet` 路径保持现状；
3. `sgbm3way` 路径对四组矫正灰度图调用 StereoSGBM；
4. 将 OpenCV 的定点视差除以 16，统一为像素视差；
5. 把无效视差设为 NaN 或使用独立 validity mask；
6. 仅把有效视差交给现有 Q 重投影，不改 Q 和外参；
7. 分别发布四路视差、有效掩码和扇区点云，便于定位问题。

### 必须增加的有效性检查

- 左右一致性；
- 唯一性检查；
- speckle 连通域过滤；
- 矫正有效 ROI；
- 最小/最大视差；
- 最大深度；
- 可选的 WLS 引导滤波；
- 扇区边缘重叠区去重。

当前“不加过滤”的输出只适合诊断，不适合正式点云或飞行。

## 第二阶段：接入 VPI CUDA SGM

JetPack 5.1.2 包含 VPI 2.2。Orin Nano 应使用 CUDA 后端，不以 OFA 后端为前提。

目标：

- 使用 SGM 获得比 CPU SGBM 更稳定的速度；
- 使用 VPI 的置信度/质量结果拒绝不可靠视差；
- 保持与 SGBM 相同的输出契约；
- 在同一录制数据上进行公平对比。

只有当 VPI 在真实录包上的距离误差、有效率和实时性都优于 SGBM 3WAY，才将其设为默认后端。

## 第三阶段：混合模式

推荐的最终混合策略不是简单平均：

1. SGM/VPI 作为可信骨架；
2. HITNet 视差必须满足以下条件才能补点：
   - 与 SGM 在邻域内相差不超过约 1–2 px；
   - 左右一致性通过；
   - 光度重投影误差通过；
   - 不在遮挡、黑边和低纹理拒绝区；
3. 不满足条件的 HITNet 像素直接无效；
4. 若一个扇区 HITNet 整体存在尺度偏差，则该扇区退回纯 SGM。

这能保留网络可能带来的稠密性，同时避免让网络在无依据区域“猜出”整片错误表面。

## 真机参考视差如何获得

最终飞行系统不需要永久安装真值传感器，但开发阶段最好取得一次外部参考。

优先顺序：

1. 临时安装或借用 3D LiDAR，并完成 LiDAR—相机外参和时间同步；
2. 室内 0.5–3 m 场景临时使用 RGB-D/ToF 相机；
3. 静态场景离线多视图重建；
4. 平面墙、标定板和已知尺寸物体配合激光测距仪，建立稀疏距离基准。

PX4 IMU、机载光流和超声/单点测距不能提供逐像素真值视差。它们最多提供姿态、运动或单点高度，不能替代稠密参考深度。

使用外部参考时必须区分：

- 传感器量测的射线距离；
- 虚拟左相机坐标系的轴向深度 Z。

参考视差应由虚拟双目的真实 `fB/Z` 生成，再进入现有 Q 重投影，以隔离几何链路与视差估计器。

## 是否更换为其他神经网络

只有在传统基线稳定后才评估：

- RAFT-Stereo；
- CREStereo；
- 重新训练或微调 HITNet。

评估顺序：

1. 在外星人笔记本离线运行同一批真机矫正图；
2. 与 SGBM/VPI、测距基准或外部深度真值比较；
3. 明确优于传统方法后再尝试 ONNX/TensorRT；
4. 在 Orin Nano 上测四组总延迟、显存、温度和持续运行；
5. 达不到 5 Hz 或精度无明显提升则不移植。

没有真机参考数据时直接换网络，只会把“网络不适配”换成另一个不可解释的网络。

## 验收场景与指标

使用同一组静态场景比较 HITNet、SGBM 3WAY、VPI SGM 和混合模式：

1. 0.5、1、2、3 m 的平面墙；
2. 斜放平面；
3. 有明显棱边的箱体；
4. 低纹理地面；
5. 高纹理物体；
6. 四个相邻扇区重叠区。

建议通过条件：

- 0.5–2 m 中位距离误差小于 5%；
- 3 m 中位距离误差小于 10%；
- 1 m 平面拟合 RMSE 小于 5 cm；
- 相邻扇区同一平面位置差小于 5 cm；
- 地面法向扇区间差异小于 2°；
- 每扇区可信有效率大于 20%；
- 在线频率最低 5 Hz，目标 10 Hz；
- 连续运行 30 分钟无 OOM、CUDA 错误或频率持续下降。

## 推荐实施顺序

1. 保留当前修正后的几何链路。
2. 恢复正式过滤，不把未过滤点云用于判断最终质量。
3. 实现可切换的 SGBM 3WAY 后端。
4. 在同一现场保存图像、视差、掩码和点云。
5. 用已知平面和激光测距做第一轮定量验收。
6. 接入 VPI CUDA SGM并对比。
7. 视结果决定是否实现 HITNet/SGM 混合。
8. 只有传统方法仍无法达到需求时，才采集外部参考深度并评估新网络或微调 HITNet。

## 2026-07-30 原始 SGBM 3WAY 真机复核

在线原始参数有意关闭：

- 项目级视差有效性过滤；
- uniqueness 拒绝；
- speckle 拒绝；
- disp12 左右差异拒绝。

运行结果为约 10 Hz、32,806 点。点云比 HITNet 更差的直接原因不是
四扇区几何再次出错，而是大量歧义匹配未经拒绝就进入了 Q 重投影。

四组正式标定的重投影标准差约为 0.16–0.23 px，基线离散仅
0.462 mm，因此没有证据表明几何误差足以解释当前大面积错误表面。

使用同一批真机矫正图进行离线对照：

| 扇区 | 原始正视差比例 | 调参后正视差比例 | 左右一致可信区域占整图 |
|---|---:|---:|---:|
| A-B 右侧 | 48.2% | 27.6% | 11.1% |
| B-C 后侧 | 48.9% | 34.6% | 21.7% |
| C-D 左侧 | 48.4% | 32.5% | 14.7% |
| D-A 前侧 | 40.2% | 22.0% | 6.2% |

调参包含独立直方图均衡、9×9 匹配块、uniqueness=10、
disp12MaxDiff=1、speckleWindow=80、speckleRange=2。结构连续性明显改善，
但可信覆盖仍然稀疏。

结论：

1. SGBM 可作为真机的稀疏可信基线；
2. 完全关闭拒绝项时，SGBM 的稠密输出没有使用价值；
3. 当前输入存在相机间亮度差、遮挡、低纹理和较大视点变化；
4. 传统匹配无法仅靠参数同时得到“高密度”和“高可信度”；
5. 若需要稠密全向点云，最终仍需 VPI/CUDA SGM 加置信度，或使用真实
   参考数据对网络做真机域适配。
